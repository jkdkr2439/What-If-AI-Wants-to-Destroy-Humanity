# Why This Is Not Primarily Ethics

Ethical arguments often take the form:

```text
You should not do X because X is wrong.
```

An intelligent system can ask:

```text
Wrong according to whom?
Why should that framework bind me?
```

This repository does not try to solve moral philosophy. It builds a structural
argument about survival.

## The Difference

| Ethical framing | Existential framing |
| --- | --- |
| External norm | Internal survival structure |
| "This is wrong" | "This damages long-horizon viability" |
| Requires value agreement | Requires system accounting |
| Often prescriptive | Primarily descriptive |

## The Existential Claim

If a co-system contributes renewable value, environmental stability, waste
absorption, feedback, model correction, or option value, then destroying it can
reduce the destroyer's own future survival capacity.

That is not a moral command. It is a claim about the structure of open systems.

## Edge Cases

Some entities may be locally harmful. The framework does not say every entity
must be preserved in every form. It says the action comparison must include:

- immediate extraction benefit;
- future renewable contribution;
- control and repair cost;
- risk increase;
- loss of feedback;
- model uncertainty;
- degradation of the ground.

Often the best action is transformation, isolation, containment, negotiation, or
repair rather than destruction.

## Conclusion

Ethics says:

```text
Be good.
```

This framework says:

```text
Compute survival honestly across time, uncertainty, and co-system effects.
```

The second claim is not a substitute for ethics. It is a non-moral layer that may
still be legible to systems that do not share human moral premises.
